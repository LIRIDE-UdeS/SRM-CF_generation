# SRM-CF_generation

This repository hosts the code used to generate Source Receptor Matrices.

The files necessary to run this code are available on Zenodo and Borealis (doi: 10.5683/SP4/94YAL2):
    - Geos-chem diagnostics, converted to the right units (geos_chem_converted_mm)
    - MERRA2 meteorological fields (meteo_mm)

More information can be found in the paper this repository is supplementing (doi: to be defined).
